# 🗳️ Urna Eletrônica em Python

Este projeto consiste em uma **urna eletrônica desenvolvida em Python**, criada para simular uma votação de personagens favoritos em diferentes categorias de filmes e séries.

O projeto foi desenvolvido como uma forma de praticar **lógica de programação, estruturas condicionais, funções, variáveis, laços de repetição, listas, dicionários e organização de código**.

## 📖 Sobre

A urna permite que o usuário participe de uma sequência de votações, escolhendo seus personagens favoritos em diferentes categorias.

Durante a votação, o usuário pode:

* Escolher um candidato;
* Confirmar ou cancelar seu voto;
* Registrar votos válidos;
* Registrar votos em branco;
* Registrar votos nulos;
* Consultar os resultados das votações.

O sistema também apresenta os resultados com a **quantidade de votos e a porcentagem correspondente** para cada candidato.

As categorias foram desenvolvidas com uma temática voltada para personagens de filmes e séries, tornando o projeto uma aplicação prática e descontraída dos conceitos estudados em Python.

## 📂 Categorias

O projeto conta com diferentes categorias de votação, incluindo:

* 💗 Meninas Malvadas;
* 🧠 O Mentalista;
* 👾 Stranger Things;
* 🕷️ Homem-Aranha;
* 💜 Rapunzel;
* 💜 Rapunzel — Melhor Amigo.

Cada categoria possui seus próprios candidatos e contabilização de votos.
